# Engine

Measure your VO2 max, find the habits holding you back, and follow a personal 12-week plan to grow your engine.

## Features
- Five ways to estimate VO2 max (12-minute run, 1.5-mile run, 1-mile walk, resting heart rate, or a known value)
- Ratings and percentiles based on Cooper Institute norms
- Engine age, habit "leaks" check, and engine efficiency score
- Goal and pace planner with projected timelines
- 12-week plan built on the Norwegian 4x4, 30-20-10, Zone 2, and strength training
- Workout timer with audio cues
- Progress tracking, saved privately in your browser

## Run it
Open `index.html` in any browser. No install needed.

## Disclaimer
Engine gives estimates, not medical advice. Check with a doctor before hard intervals if you have a heart condition or haven't exercised in a long time.
